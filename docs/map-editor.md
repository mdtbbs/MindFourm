# 地图安全编辑器

地图工作台使用官方 Mindustry renderer 的 MapIO 读取和导出地图。它只对已发布版本产生新的 direct-upload 版本，原始地图不变。

## 支持的编辑

- 在完整、未截断的地形网格中选择现有 floor 和 overlay 并修改格子。
- 编辑已识别的布尔世界规则。
- 新增、更新、删除和调整顺序的波次组；波次字段会经过类型和范围校验。
- 导出、round-trip 校验，再进入资源版本审核流程。

## 安全边界

renderer 只接受官方 MapIO 格式，限制地图面积、变更数量和波次数量；mod 地图、未知规则字段和无法验证的结构会保持原值或使导出失败。前端当前只展示地形、规则和波次编辑，不提供方块/团队/矿脉/液体/标记的绘制工具，也不会假装这些字段已经可编辑。地形摘要超过 5000 格或被截断时，网格保存按钮会禁用。

能力开关依赖 renderer health protocol v2、固定运行时哈希、MapIO 操作声明、RES 可用性和服务端 origin 配置。服务端仍会对每次操作重新授权、锁定版本并做 round-trip 校验，不能通过修改前端请求绕过能力限制。

## 版本流程

地图保存会创建同一资源的新 revision，上传对象先保持私有并进入审核；只有审核发布后才会更新公开版本指针和绑定可见性。对象校验失败、RES 不可用或审核拒绝都不会删除或覆盖历史地图。
