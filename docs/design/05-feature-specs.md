# 功能规格说明

> 本文档记录了论坛系统的详细功能规格。
> 创建时间: 2026-06-07

## 功能清单

### 1. 帖子系统（完整版）

| 功能 | 说明 |
|------|------|
| 创建帖子 | 标题 + 正文（Markdown）+ 分类 + 标签 + 封面图 |
| 编辑帖子 | 可查看编辑历史 |
| 删除帖子 | 软删除，管理员可恢复 |
| 帖子列表 | 排序：最新、最热、精华、我的帖子 |
| 帖子详情 | Markdown 渲染，使用 react-markdown + remark-gfm |
| 阅读权限 | 公开 / 登录用户可见 / 特定用户组可见 |
| 内容目录 | 作者手动添加目录结构 |
| 附件 | 批量上传 + 断点续传 + 图片自动压缩 + 附件管理面板 |

> **编辑器说明**：使用 `react-markdown` + `remark-gfm` 渲染 GitHub 风格的 Markdown，支持代码高亮、表格、任务列表等。前端使用 textarea + 预览模式，而非富文本编辑器。

### 2. 回复系统（简单嵌套）

| 功能 | 说明 |
|------|------|
| 创建回复 | 支持 @提及 + 引用特定内容块 |
| 嵌套层级 | 最多 2 层嵌套 |
| 编辑回复 | 记录编辑历史 |
| 删除回复 | 软删除 |
| 展示方式 | 分页展示，每页 20 条 |
| 最佳答案 | 帖子作者可采纳回复为最佳答案 |

### 3. 用户系统（完整资料）

| 功能 | 说明 |
|------|------|
| 个人资料 | 头像 + 昵称 + 签名 + 个人简介 |
| 个性化 | 主页背景 + 自定义称号 |
| 成就统计 | 发帖数 + 回复数 + 获赞数 |
| 在线状态 | 实时在线状态显示 |

> **注意**：关注系统、粉丝统计、徽章展示、积分排名功能未实现。

### 4. 通知系统（全渠道）

| 渠道 | 触发事件 |
|------|----------|
| SSE 实时推送 | 所有通知类型 |
| 站内通知列表 | 所有通知类型 |
| 邮件通知 | 新回复 + @提及 + 私信通知 |

| 通知类型 | 说明 |
|----------|------|
| reply | 有人回复了你的帖子 |
| mention | 有人 @提及 了你 |
| like | 有人点赞了你的帖子/回复 |
| system | 系统通知 |
| report | 举报处理结果通知 |

> **注意**：`badge` 通知类型已移除，徽章系统未实现。

### 5. 举报系统（完整流程）

| 功能 | 说明 |
|------|------|
| 提交举报 | 选择原因（spam/harassment/等）+ 描述 |
| 进度跟踪 | 用户可查看举报处理进度 |
| 反馈通知 | 举报处理结果通知举报者 |
| 管理员处理 | 通过 / 驳回 / 封禁用户 |
| 审核记录 | 所有处理操作记录在案 |

### 6. 管理后台（完整管理）

| 模块 | 功能 |
|------|------|
| 仪表盘 | 今日新增 + 7 天趋势 + 热门分类 + 活跃用户排行 |
| 用户管理 | 列表 + 搜索 + 角色分配 + 封禁 + 批量操作 + 详情 + 日志 |
| 帖子管理 | 列表 + 状态更新 + 置顶 + 删除 |
| 举报处理 | 举报列表 + 处理 + 结果通知 |
| 系统设置 | 基础/SEO/邮件/认证/内容配置 |
| 公告管理 | 创建 + 编辑 + 删除 + 启用/禁用 |
| 敏感词管理 | DFA 词树 + 审核记录 + 自动替换/阻止发布 + 批量导入 |
| 资源管理 | 资源审核 + 状态更新 + 删除 |
| 日志管理 | 操作日志查询 + 清理旧日志 |

> **注意**：用户等级、用户组、积分商城、插件管理功能未实现。

### ~~7. 插件系统~~（未实现）

> **注意**：插件系统已规划但未实现。以下功能暂不可用：
> - 插件上传安装
> - 插件启用/禁用
> - 插件配置面板
> - 钩子系统（before/after/filter）
> - 依赖检查

### 8. 其他功能

| 功能 | 说明 |
|------|------|
| 点赞收藏 | 帖子点赞 + 收藏 |
| 分类标签 | 帖子分类 + 标签系统 |
| 私信系统 | 一对一私信（群聊未实现） |
| 搜索 | MySQL LIKE 搜索（后期全文索引） |
| 深色模式 | 全站深色/浅色主题切换 |

> **注意**：RSS 订阅功能未实现。
