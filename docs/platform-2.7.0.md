# MindFourm 2.7.0 平台能力收口

2.7.0 将 Resource Center、renderer 编辑器、搜索、社交和移动端路径收口到同一套权限、能力发现、对象存储和审核合同。

## 本版本完成

- ResourceStorage metadata-first direct upload：浏览器只上传到 RES，论坛在 complete 阶段重新读取权威对象元数据、校验哈希/大小/状态并创建私有绑定。
- 资源对象/绑定对账：管理员只读扫描、发现分类、安全降级/重绑、双阶段 operation log 审计；没有自动 GC、自动删除或生产迁移。
- 蓝图和地图轻编辑器：官方 renderer 协议 v2、固定运行时哈希、操作白名单、round-trip 校验和新版本审核路径。
- 统一搜索：资源过滤、全文索引维护、viewer 隐私/屏蔽过滤、建议和有限编辑距离纠错；旧 `/api/search` 也传递 viewer 和资源过滤条件。
- 社交/联机：隐私设置、好友邀请/加入请求、可恢复 realtime ticket、移动端好友和搜索 smoke。

## 证据层

本地提交包含后端单测、构建、前端 typecheck/lint 和现有 E2E workflow 接入；renderer 的 Java 构建以 CI 的 Java 17 fixture 为准，当前开发机没有 JDK，不能把本地 renderer 构建报告为通过。生产部署、生产迁移和历史文件删除不属于本版本验收。

## 已知限制

- 地图编辑器当前只编辑完整地形网格、已识别布尔规则和波次；方块、团队、资源、液体、标记绘制仍会安全降级。
- 蓝图编辑器不执行逻辑，不编辑未知二进制配置或 mod 方块；超出边界时必须回到原文件或使用离线工具。
- RES 对账报告需要管理员读取两个服务的清单；RES 不可用时只记录请求审计，不猜测对象状态。
