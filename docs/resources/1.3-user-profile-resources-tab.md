# 1.3 用户主页资源标签

## 完成状态
✅ **已完成**

## 概述
在用户个人主页添加"资源"标签页，展示该用户发布的已批准且公开的资源。所有访客都可以看到其他用户的资源贡献，这是展示用户社区贡献的重要组成部分。

## 实现细节

### 后端修改

#### 1. 添加获取用户公开资源方法
**文件**: `src/modules/resources/resources.service.ts`

**新增方法**: `getPublicByUserId(userId, limit, cursor)`

```typescript
async getPublicByUserId(
  userId: number,
  limit: number = 20,
  cursor?: string,
): Promise<any>
```

**功能**:
- 只返回 `status: 'approved'` 且 `is_public: 1` 的资源
- 支持游标分页（cursor-based pagination）
- 按创建时间倒序排列
- 包含用户和分类信息

**实现**:
```typescript
const where: any = {
  user_id: userId,
  status: 'approved',
  is_public: 1,
};

const resources = await this.resourceRepository.find({
  where: cursorCondition.length > 0
    ? [{ ...where, ...cursorCondition[0] }, { ...where, ...cursorCondition[1] }]
    : where,
  relations: ['user', 'category'],
  order: {
    created_at: 'DESC',
    id: 'DESC',
  },
  take: Number(limit) + 1,
});
```

#### 2. 添加公开 API 端点
**文件**: `src/modules/resources/resources.controller.ts`

**新增端点**: `GET /api/resources/user/:userId`

```typescript
@Get('user/:userId')
@OptionalAuth()
@UseGuards(JwtAuthGuard)
async getUserResources(
  @Param('userId', ParseIntPipe) userId: number,
  @Query() query: QueryResourcesDto,
  @Req() req?: any,
) {
  // Public endpoint: only returns approved and public resources
  return this.resourcesService.getPublicByUserId(
    userId,
    query.limit,
    query.cursor,
  );
}
```

**特点**:
- 使用 `@OptionalAuth()` 允许未登录用户访问
- 只返回已批准且公开的资源（隐私保护）
- 支持分页参数（limit, cursor）
- 无需权限验证（公开信息）

#### 2. 添加数据获取函数

```typescript
async function fetchUserResources(
  userId: number,
  page: number,
): Promise<{ data: Resource[]; pagination: PostListResponse['pagination'] }> {
  return fetchApiPaginated<Resource>(
    `/api/resources/user/${userId}?page=${page}&limit=20`,
    {
      init: { cache: 'no-store' },
      fallback: createEmptyPaginatedResult<Resource>(20),
    },
  );
}
```

#### 3. 更新数据加载逻辑
**修改**: 在 `Promise.all` 中添加资源数据获取

```typescript
const [postsResult, repliesResult, resourcesResult, bookmarksResult, likesResult] = await Promise.all([
  // ... 其他数据获取
  tabValue === 'resources'
    ? fetchUserResources(userId, page)

  // ...

```

**优化**: 只在访问资源标签页时才加载资源数据，减少不必要的数据传输。

## 权限与隐私

### 可见性规则
- ✅ **所有用户**：可以看到其他用户的已批准公开资源
- ✅ **资源所有者**：可以看到自己的所有资源（包括待审核和私有的）
- ❌ **未批准资源**：不会在用户主页显示
- ❌ **私有资源**：不会在用户主页显示

### 与"我的资源"页面的区别
- **用户主页资源标签**：只展示已批准的公开资源，所有访客可见
- **/resources/my 页面**：展示用户自己的所有资源（包括待审核、已拒绝、私有），仅本人可见

## 性能优化

1. **按需加载**：只在访问资源标签页时才加载资源数据
2. **游标分页**：使用游标分页而非偏移分页，大数据量下性能更好
3. **缓存策略**：使用 `cache: 'no-store'` 确保数据实时性
4. **关联预加载**：使用 `relations: ['user', 'category']` 避免 N+1 查询
