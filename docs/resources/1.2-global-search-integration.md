# 1.2 资源接入全局搜索

## 完成状态
✅ **已完成**

## 概述
将资源模块集成到全局搜索系统中，用户可以在搜索页面同时搜索帖子和资源。搜索结果会分别显示资源（最多20条）和帖子（分页显示）。

## 实现细节

### 后端修改

#### 1. 更新 SearchModule
**文件**: `src/modules/search/search.module.ts`

- 添加 `Resource` 实体到 `TypeOrmModule.forFeature()` 导入列表

#### 2. 扩展 SearchService
**文件**: `src/modules/search/search.service.ts`

**新增方法**: `searchResources(query: string, limit: number = 20)`

```typescript
async searchResources(query: string, limit: number = 20): Promise<any[]>
```

**功能**:
- 搜索已批准（`status: 'approved'`）且公开（`is_public: 1`）的资源
- 匹配标题（`title`）和描述（`description`）字段
- 使用 `escapeLike()` 防止 SQL 注入
- 按下载量、评分、创建时间排序
- 返回资源的关键信息（id、标题、描述、类型、版本、下载量、评分等）

**实现**:
```typescript
const resources = await this.resourceRepository.find({
  where: [
    {
      status: 'approved',
      is_public: 1,
      title: Like(`%${escapeLike(query)}%`),
    },
    {
      status: 'approved',
      is_public: 1,
      description: Like(`%${escapeLike(query)}%`),
    },
  ],
  relations: ['user', 'category'],
  order: {
    download_count: 'DESC',
    rating_average: 'DESC',
    created_at: 'DESC',
  },
  take: limit,
});
```

#### 3. 更新 SearchController
**文件**: `src/modules/search/search.controller.ts`

**修改**: `GET /api/search` 端点

- 使用 `Promise.all()` 并行查询帖子和资源
- 在响应中添加 `resources` 字段
- 保持原有的帖子分页功能不变

```typescript
const [postsResult, resources] = await Promise.all([
  this.searchService.searchPosts(dto.q, { ... }),
  this.searchService.searchResources(dto.q, 20),
]);

return {
  ...postsResult,
  resources,
  popular_searches: await this.searchService.getPopularSearches(),
};
```

## 搜索结果排序规则

### 资源排序
1. 下载量（`download_count`）- 降序
2. 平均评分（`rating_average`）- 降序
3. 创建时间（`created_at`）- 降序

### 帖子排序
- 保持原有的排序逻辑（相关性、最新、最旧）

## 安全考虑

1. **SQL 注入防护**: 使用 `escapeLike()` 转义特殊字符
2. **权限控制**: 只返回已批准且公开的资源
3. **速率限制**: 保持原有的 30次/分钟 限制
4. **数据隔离**: 私有资源和待审核资源不会被搜索到

## 性能优化

1. **并行查询**: 使用 `Promise.all()` 同时查询帖子和资源
2. **结果限制**: 资源最多返回 20 条，避免大量数据传输
3. **索引利用**: 利用已添加的资源索引加速查询
4. **关联预加载**: 使用 `relations` 预加载 user 和 category，避免 N+1 查询
