# MDTBBS 产品更新日志

本页记录面向论坛用户和第三方开发者的主要产品变化。API 字段、权限和接口兼容性由 [Public API 更新记录](/api/v1/docs/changelog)维护。条目按论坛版本（见[论坛版本规则](../VERSION_RULE.md)）从新到旧排列；只改版本号的发布不会产生用户可见变化。

## 2.7.12 — 中文文案与编辑器限流修复

- 修正中文界面里混入其他站点名称、把内部实现语气当作用户文案的表述，并让站点名称在服务端解析，法律页面不再出现硬编码站点名。
- 编辑器数据接口限流从 5 次提高到 60 次/分钟，正常编辑时不再频繁触发限流。

## 2.7.11 — 玩家资源编辑器

- 资源详情直接打开所选版本的蓝图或地图编辑器；公开资源人人可编辑并下载副本，登录后可发布自己的作品。
- 三个工具页支持本地文件，蓝图支持框选/复制粘贴，地图支持分区绘制与对象操作，波次支持配置导入、模板和数量预览；操作共用撤销/重做。
- 改善官方中文内容选择、移动端控件与版本数据显示，修复贴边蓝图旋转和地图规则 JSON 返回格式。导出保留官方读写验证，发布保留 RES 上传与审核。

## 2.7.10 — 富文本呈现统一

- 编辑、预览和已发布正文共用同一套正文样式与语法高亮，标题宽度、表格、任务列表、剧透和卡片在三种状态下保持一致。
- 新建和编辑帖子改为单栏标签页切换，预览直接读取当前内容；编辑面板只是隐藏，不会丢失光标、撤销历史和未提交内容。
- 视频只在读者主动操作后加载允许列表内的播放器；附件草稿的显示信息仍只保存在本地，不写入正文数据。

## 2.7.8–2.7.9 — 云存档上传与接口转发

- 云存档大文件上传改为流式转发，不再把整个文件读入内存；入口经过 Next.js 时由专用路由处理，通用接口转发在其后兜底。
- 反向代理需要为该上传路径关闭请求缓冲并放开请求体上限，部署说明已同步。

## 2.7.7 — 社区与资源导航

- 社区讨论分类和资源类型可在桌面侧栏折叠查看，默认收起，减少导航占用。

## 2.7.5–2.7.6 — 信息架构、投稿与导航

- 前台信息架构收敛为首页、社区、资源、联机、工具、我的六个一级空间；桌面侧栏固定六项，移动端保留五个底部标签，全局搜索、创建入口和工具中心随之调整。
- Mod 增加独立投稿页，外部来源投稿必须填写 Mod ID，减少同名或错填资源。
- 资源发现结果改用规范详情链接。

## 2.7.3–2.7.4 — 资源发现修复

- 修正资源发现的查询参数转换和详情链接，筛选、排序和跳转不再失效。

## 2.7.2 — 资源发现与 API 文档

- 增加论坛功能概览、产品更新日志和公开计划入口，方便用户与开发者了解当前功能和后续方向。
- Public API 契约更新至 `1.2.0`。资源发现接口公开精选、趋势、上升、评分、最新、下载榜和推荐结果的算法版本、分数与原因；评分公式、信号窗口、分页与隐私边界见[资源 API 文档](/api/v1/docs/resources)。API 路径仍为 `/api/v1`，没有移除现有公开操作。

## 2.7.0–2.7.1 — 资源与发现体验

- 改进 Mod、地图和蓝图的资源信息、版本管理、搜索筛选与兼容信息。
- 增加更直接的资源投稿方式，以及蓝图和地图的有限在线编辑；编辑结果作为新版本提交。
- 改善资源可见性、安全审核和社交/移动端流程。
- Public API 契约更新至 `1.1.0`：补充资源类型化读写、上传会话、统一搜索参数和公开发现榜单，既有公开操作与字段语义保持兼容。
- 平台能力、证据层和已知限制详见 [`platform-2.7.0.md`](../platform-2.7.0.md)。

## 2.6.2–2.6.4 — ResourceStorage 接入与发布收尾

- 资源文件改为经 ResourceStorage 交付：直传、内容寻址去重、绑定生命周期和交付方式选择都在这一阶段落地；论坛只保存资源业务元数据。
- 上传内容先进入隔离区，通过审核后才发布；审核失败或拒绝时保留隔离文件。
- 2.6.2 完成资源、API 与安全审计的发布候选验收修复。
- 2.6.3 只包含版本号修复，没有用户可见变化。
- 2.6.4 把公开 API 文档、更新记录与工程说明对齐到当时的实现。

## 2.3.0–2.6.1 — Resource Center V2

- Resource Center V2 引入不可覆盖的版本 revision、成员与所有权、审核事件、兼容性、依赖、分析、manifests 和 GitHub Release 来源同步。
- 发布已使用过的显示版本会创建新 revision，不覆盖已发布文件。
- 资源版本说明支持富文本，资源详情补齐内容关系、预览与安全审核边界。

## 2.2.0 — 管理后台、国际站点与手机号验证

- 管理后台重做为 2.0 结构，包含双栏导航、全局命令菜单和重建后的运营、审核、用户与资源页面。
- 引入 `mindustry-club` 站点 profile 和国际社区基线：语言、验证策略与功能开关按 profile 分离，两站使用独立数据库、Redis、上传目录和凭据。
- 重做手机号安全验证流程与合规说明；MDTBBS 站点的社区写入要求已完成手机号验证。
- 语言切换移入顶部工具栏，并为多语言界面补齐缺失翻译。

## 2.1.0 — 平台化起点

- 论坛接入 MindAuth OAuth，QQ 登录改由认证服务承担，论坛侧不再自行维护该流程。
- 引入第一方 V1 接口层、内置开发者文档与 OpenAPI 在线参考。
- 资源中心补充版本说明、反应、屏蔽、举报、帖子锁定与采纳答案等社区能力。

## 1.0–2.0 — 论坛与社区基础

- 从讨论、回复和用户资料起步，逐步补充通知、私信、关注、收藏、好友、群组和内容互动。
- 从 SQLite 迁移到 MySQL 8 + Redis，加入搜索历史、@提及、邮件队列、限流与封禁等基础能力。
- 资源中心从浏览、投稿起步，逐步加入分类、筛选、审核和版本管理。

以上版本区间总结主要功能变化，不能替代每个补丁版本的逐项变更说明，也不表示所有站点在同一天完成部署。当前实现范围见[功能概览](/api/v1/docs/product-overview)，已确认的研发方向见[公开计划](/api/v1/docs/product-roadmap)。
