# MDTBBS 产品更新日志

本页记录面向论坛用户和第三方开发者的主要产品变化。API 字段、权限和接口兼容性由[Public API 更新记录](/api/v1/docs/changelog)维护。历史条目按功能阶段汇总，不逐项列出补丁修复。

## 2.7.7 — 社区与资源导航

- 社区讨论分类和资源类型可在桌面侧栏折叠查看，默认收起，减少导航占用。

## 2.7.2 — 资源发现与 API 文档

- 增加论坛功能概览、产品更新日志和公开计划入口，方便用户与开发者了解当前功能和后续方向。
- Public API 契约更新至 `1.2.0`。资源发现接口公开精选、趋势、上升、评分、最新、下载榜和推荐结果的算法版本、分数与原因；评分公式、信号窗口、分页与隐私边界见[资源 API 文档](/api/v1/docs/resources)。API 路径仍为 `/api/v1`，没有移除现有公开操作。

## 2.7.0–2.7.1 — 资源与发现体验

- 改进 Mod、地图和蓝图的资源信息、版本管理、搜索筛选与兼容信息。
- 增加更直接的资源投稿方式，以及蓝图和地图的有限在线编辑；编辑结果作为新版本提交。
- 改善资源可见性、安全审核和社交/移动端流程。

## 2.3–2.6 — 客户端与社区能力扩展

- 扩展第三方 Public API、MindAuth OAuth 接入和富文本内容支持。
- 增加云存档、多人联机、好友邀请和在线状态相关功能；可用性取决于站点当前开放的服务能力。
- 资源中心逐步加入版本、协作、兼容性和审核相关能力。

## 1.0–2.2 — 论坛与社区基础

- 从讨论、回复和用户资料起步，逐步补充通知、私信、关注、收藏、好友、群组和内容互动。
- 持续完善游戏资源的浏览、投稿和社区参与流程。

以上版本区间总结主要功能变化，不能替代每个补丁版本的逐项变更说明，也不表示所有站点在同一天完成部署。当前实现范围见[功能概览](/api/v1/docs/product-overview)，已确认的研发方向见[公开计划](/api/v1/docs/product-roadmap)。
