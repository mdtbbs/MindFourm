# MDTBBS 论坛功能概览

MDTBBS 是围绕 Mindustry 社区的论坛和游戏内容分享平台。这里介绍普通用户可见的主要功能，以及第三方开发者可接入的公开能力。

论坛软件版本与 Public API 契约版本分别管理。API 请求路径仍为 `/api/v1`；当前 OpenAPI 契约版本为 `1.2.0`。不同站点和功能开放状态可能不同，客户端应读取[服务能力](/api/v1/docs/public-client)后再显示对应入口。

## 当前功能

### 讨论与社区互动

- 发布讨论、回复和个人资料内容，并浏览分类与社区动态。
- 使用通知、私信、关注、好友、收藏、点赞和屏蔽等社区功能；具体入口随站点开放情况而异。
- 使用支持结构化排版的富文本编辑器发布内容。

### Mindustry 游戏内容与资源

- 浏览、搜索、预览和下载 Mod、地图与蓝图，并查看版本、兼容信息和内容关系。
- 使用公开资源发现 API 读取精选、趋势、近 7 日上升、评分榜、最新、下载榜、猜你喜欢和相关推荐；结果包含算法版本、分数和可解释原因，计算口径见[资源中心 API](/api/v1/docs/resources)。
- 投稿资源、管理资源版本，并在支持的流程中邀请协作者、处理审核意见和更新来源。
- 通过筛选和排序查找社区内容。资源详情、版本与下载状态以页面显示为准。

### 游戏客户端与第三方工具

- 第三方客户端可使用稳定的 Public API V1 接入讨论、游戏内容、资源、用户状态等功能。
- MindAuth OAuth 与 PKCE 用于第三方客户端授权。API 不要求客户端收集论坛密码。
- 当前公开契约还包含云存档、多人联机和社交状态相关操作；每项能力是否开放由站点能力设置决定。

### 资源编辑

支持的站点提供蓝图和地图的有限编辑流程。编辑结果以新版本提交；当前并非所有地图对象、蓝图配置和游戏内容都可在线编辑。超出编辑范围的内容仍可通过原资源查看或下载。

## 从 1.0 到当前版本

以下按主要功能里程碑概述演进，不是每个补丁版本的完整发布清单。

- **1.0.0 起点（2026 年 5 月）：** 建立论坛讨论、回复、用户资料和基础社区内容浏览能力。
- **社区能力扩展（2026 年 5 月至 8 月）：** 持续补充通知、收藏、关注、好友、群组、内容互动和社区管理功能，并扩展游戏资源发布与浏览流程。
- **资源中心与客户端接入（2026 年 9 月）：** 资源能力扩展到 Mod、地图和蓝图的版本、兼容与关系信息；发布 Public API V1 和第三方 OAuth 接入文档；讨论正文支持更丰富的排版结构。
- **游戏内容与跨设备体验（2026 年 10 月）：** 增加云存档、多人联机和社交状态 API；完善资源搜索与筛选、上传流程，以及蓝图和地图的有限在线编辑能力。

历史功能阶段按代码库中可核实的合并记录整理，不代表某个站点的实际部署日期。面向用户的近期变化见[产品更新日志](/api/v1/docs/product-changelog)；第三方接口变化见[API 更新记录](/api/v1/docs/changelog)。
