# MDTBBS 公开计划与功能下线

**更新日期：2026 年 10 月 9 日。** 本页只列出已公开的产品方向和已发布的功能下线通知。研发方向可能调整；没有发布日期的项目不代表对上线时间作出承诺。

## 正在推进的方向

截至本页更新时，以下面向用户的方向仍处于研发草稿阶段，尚未进入正式版本计划：

- 继续完善蓝图和地图编辑的对象、配置覆盖范围，减少需要回到离线工具的场景。
- 改善资源中心及编辑流程的手机端使用体验。
- 把 Android 客户端补齐到与当前平台能力一致：先解决授权链路和富文本正文，再补首页聚合、回复分页与子回复、私信、资源中心与多人联机。当前实现状态和优先级见 [`ANDROID-CLIENT-STATUS.md`](../android/ANDROID-CLIENT-STATUS.md)。
- 改进资源发现和推荐。

这些内容处于研发与评审过程中，范围和时间都可能调整。正式发布后会在[产品更新日志](/api/v1/docs/product-changelog)中确认实际交付内容。

已交付的编辑器能力（蓝图/地图/波次工具页、本地文件与公开资源副本、游客导出）属于当前版本功能，不再列为计划项。

## 功能下线与 API 弃用

目前没有已公布的论坛用户功能下线计划。Public API V1 目前也没有已弃用的操作；现有公开接口没有公布移除日期。若将来计划弃用接口，会先在[API 生命周期说明](/api/v1/docs/lifecycle)中公布替代方案和迁移期限。

投票和完整的用户群聊体验当前尚未实现，也没有公布上线时间。它们不属于已确认的近期路线图。
