# MindForum 前端设计文档

## 项目概述

基于 MindForum 后端 API 开发现代化论坛前端，采用简洁现代 + 社区风格的混合设计，XenForo 风格的数据交互方式。

### 技术栈

| 类别 | 技术 | 说明 |
|------|------|------|
| 框架 | Next.js 14+ | App Router，SSR 渲染 |
| 语言 | TypeScript | 类型安全 |
| 样式 | TailwindCSS | 原子化 CSS |
| 状态 | React Context | 仅用于认证状态 |
| HTTP | fetch API | 原生，配合 Next.js cache |
| Markdown | react-markdown + remark-gfm | GitHub 风格渲染 |
| 表单 | 自开发 | 原生实现，配合 Server Actions |
| 图标 | Lucide React | 轻量图标库 |

## 认证流程

### 流程设计

```
用户访问论坛
    ↓
检查 localStorage 是否有 mindauth_session_token
    ↓
有 → 调用 POST /api/auth/verify-session
    ↓ 成功 → 设置 forum_session cookie，登录完成
    ↓ 失败 → 清除本地 token，未登录状态
    ↓
无 → 未登录状态，页面可正常浏览
    ↓
用户点击"登录"
    ↓
跳转 MindAuth 登录页 (MINDAUTH_URL/login?redirect=...)
    ↓
MindAuth 登录成功，回调 /api/auth/callback?code=xxx
    ↓
后端设置 forum_session cookie
    ↓
前端重定向首页，登录完成
```

### 关键实现点

1. **Session Token 检测**：页面加载检查 MindAuth session token，尝试自动登录
2. **Cookie 认证**：`forum_session` cookie（httpOnly），API 请求自动携带
3. **登录状态检查**：`GET /api/auth/check` 获取用户信息
4. **权限保护**：后台页面组件内权限检查，未授权跳转首页
5. **Logout**：`POST /api/auth/logout`，清除 cookie 和本地存储

## 数据策略

采用 XenForo 风格，SSR 为主：

- 每次操作都是新请求，无客户端缓存
- 传统分页导航，非无限滚动
- JavaScript 仅用于增强交互，不管理数据状态
- 表单提交后重定向刷新页面

## 错误处理

| 场景 | 处理 |
|------|------|
| API 失败 | 显示错误提示 |
| 401 | 前端可浏览，后台跳转首页 |
| 403 | 显示"无权限" |
| 404 | 显示"内容不存在" |
| 500 | 显示"服务器错误"，建议刷新 |
| 网络错误 | 显示"连接失败"，提供重试 |

## 安全

| 安全点 | 实现 |
|--------|------|
| XSS | react-markdown 自动过滤 |
| CSRF | Cookie httpOnly |
| 权限 | 前端 UI + 后端 API 双重校验 |
| 敏感信息 | email 仅自己可见 |

## 响应式设计

### 断点

| 断点 | 宽度 | 设备 |
|------|------|------|
| sm | < 640px | 移动端 |
| md | 640px - 1024px | 平板 |
| lg | ≥ 1024px | 桌面 |

### 适配策略

**首页**：
- 桌面：左侧分类导航 + 右侧帖子列表
- 平板：分类折叠为顶部标签栏
- 移动：分类下拉菜单，帖子单列

**帖子详情**：
- 桌面：内容居中 800px
- 平板/移动：全宽

**后台管理**：
- 桌面：固定侧边栏
- 平板：侧边栏可折叠
- 移动：侧边栏隐藏，顶部导航
